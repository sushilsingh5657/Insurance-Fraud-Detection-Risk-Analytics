# Insurance Fraud Detection & Risk Analytics

## Overview

This project analyzes insurance claim data to identify fraud patterns and risk factors using Python, SQL, and Power BI.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- MySQL
- Power BI

## Project Workflow

1. Data Cleaning
2. Exploratory Data Analysis
3. SQL Business Queries
4. Dashboard Development
5. Business Insights

## Key Findings

- Fraud rate is approximately 5.99%.
- Male policyholders account for most fraud cases.
- Adult customers show the highest fraud volume.
- Claims without witnesses are more likely to be fraudulent.
- Sedan vehicles generate the highest fraud claims.
